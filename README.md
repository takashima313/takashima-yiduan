# Takashima — I‑Ching Decision Matrix

This is a fully‑offline frontend I‑Ching divination tool.
No backend server, no data collection, no network calls after download.

All functions run locally inside your browser.
Download the source files, open index.html, you can use the program immediately.

The project is completely open‑source, free for everyone, no commercial purpose.
Released under Apache‑2.0 license.

There is no team, no fundraising, no token issuance.
This is an independent anonymous research work.
Everyone is welcome to view, use, study and improve this code.
