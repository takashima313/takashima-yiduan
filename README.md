# TAKASHIMA YIDUAN 高岛易断
TAKASHIMA YIDUAN is a free and open-source multilingual I Ching divination and reflection tool, implemented as a single-file HTML application.

It can be opened directly in any standard web browser without installing additional software. The application runs locally on the user's device and does not require a backend server, user account, or upload of user data.

This project is an independent research project with no commercial access requirements. The source code is publicly released worldwide under the MIT License and Apache License 2.0 for inspection, study, research, and practical use.

## How to Use
Download or clone this repository, then open index.html in a standard web browser.
No installation or backend server is required.
