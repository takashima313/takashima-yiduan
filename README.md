# TAKASHIMA YIDUAN 高岛易断

**TAKASHIMA YIDUAN** is a free and open-source multilingual **I Ching divination and reflection tool**, implemented as a single-file HTML application.

It can be opened directly in any standard web browser without installing additional software.

The application runs locally on the user's device and does **not** require:

* a backend server
* a user account
* cloud storage
* uploading user data
* additional software installation

TAKASHIMA YIDUAN is an **independent research project** with no commercial access requirements.

The source code is publicly released worldwide under the **MIT License** and **Apache License 2.0** for inspection, study, research, modification, and practical use.

## What Is TAKASHIMA YIDUAN?

TAKASHIMA YIDUAN is an open-source digital tool for exploring the **I Ching (Yi Jing / Zhouyi)** through divination, interpretation, and personal reflection.

The project is designed around a simple principle:

> **Open the tool. Ask your question. Explore the I Ching. Reflect privately.**

The application is intentionally lightweight and local-first.

It is designed to work directly in a standard web browser without requiring a centralized service.

---

## Key Characteristics

### Free

The tool is freely available for personal exploration, research, and practical use.

### Open Source

The complete source code is publicly available for inspection, study, modification, and further development.

### Offline / Local-First

The application is designed to run locally in the browser.

### No Account Required

Users do not need to create an account or register with a centralized service.

### No Backend Required

The application does not depend on a dedicated backend server for its basic operation.

### No User Data Upload Required

The project is designed so that users can use the application without uploading their questions or other personal information to a server.

### Multilingual

The project provides multilingual documentation and supports international users.

## Privacy by Design

TAKASHIMA YIDUAN follows a local-first approach.

The project does not require users to create accounts or upload their questions and personal input to a centralized backend service.

This design allows users to explore the I Ching privately on their own devices.
